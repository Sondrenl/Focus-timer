# AI Declaration

## Project: Pomodor — Focus Timer
- **Project Creator:** Sondre Lassen
- **AI Assistant:** Antigravity (Google DeepMind)
- **Development Method:** Prompt-Driven Development (AI-Generated Codebase)
- **Date:** October 2026

---

## 1. Overview
This web application was built using a **prompt-driven development approach**.

All source code, architectural structure, configurations, and bug fixes in this repository were written directly by an AI assistant (Antigravity). The creator (Sondre Lassen) guided the process by providing feature requirements, design preferences, and functional feedback through conversational prompts.

---

## 2. Code Review & Verification
- **Code Generation**: 100% of the codebase was generated by AI.
- **No Manual Code Review**: The creator has not conducted line-by-line source code inspection or manual code audits.
- **Functional Testing**: Verification was carried out interactively by using the web app in the browser—evaluating the user experience, validating feature behavior, and directing the AI to iterate or fix issues when adjustments were required.
- **Automated Build Checks**: Production build verification and TypeScript type checks (`npm run build`) were run automatically during development.

---

## 3. Scope of AI Generation
Every layer of the application was generated via AI prompts, including:
- React components, custom hooks, and state management
- Background Web Worker for timer countdown accuracy
- Web Audio API chime generation
- LocalStorage data handling for sessions, tags, and settings
- Statistics calculations and SVG charts
- Tailwind styling, layout responsiveness, and PWA setup

---

## 4. Privacy & Data Handling
The application runs entirely client-side in the user's browser:
- No account or login required.
- No network telemetry, remote servers, or analytics tracking.
- All session history, tags, and settings remain stored on the user's local device.
